## Описание проекта

В рамках лабораторной работы разрабатывается веб-приложение для просмотра авиарейсов и управления бронированиями.

Основной функционал:

- Регистрация и авторизация пользователей.
- Просмотр информации об авиарейсах.
- Бронирование мест с возможностью изменения и отмены бронирования.
- Публикация отзывов и оценок рейсов.
- Регистрация пассажиров и назначение номеров билетов администратором.
- Просмотр списка пассажиров выбранного рейса.
- Поиск, фильтрация и пагинация.
- Разграничение прав пользователей и администраторов.

В рамках практических заданий 2.1–2.3 также реализуется приложение для управления автомобилями, их владельцами и историей владения.

## Используемые технологии

- Python 3.10
- Django 3.2
- PostgreSQL
- Jinja2
- HTML/CSS

## Структура приложений

- `project_first_app` — практические задания 2.1–2.3.
- `accounts` — модели пользователей и авторизация.
- `flights` — авиарейсы, бронирования и отзывы (будет добавлено позднее).

## Установка и запуск

Все команды выполняются из каталога `laboratory_work_2`.

### 1. Создание виртуального окружения

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 2. Установка зависимостей

```powershell
python -m pip install -r requirements.txt
```

### 3. Проверка конфигурации

```powershell
python manage.py check
```

Настройка PostgreSQL, миграции и запуск веб-сервера будут описаны после реализации соответствующих этапов.
